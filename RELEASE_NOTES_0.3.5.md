# ytm-rs 0.3.5

- AppleTify is the default and only desktop theme. Existing profiles use AppleTify
  automatically and keep their light, dark or system appearance selection.
- The player bar still animates visible track changes. A track change while the
  window is minimized is shown immediately on restore, with no deferred effect.
- Includes the R7 playback, radio and AppleTify navigation source snapshot.
- Windows x64 packages are unsigned. The release includes an installer, portable
  ZIP, corresponding source, the delta from 0.3.4, and SHA-256 checksums.

AppleTify is adapted from a-dogann's Better Lyrics community theme. Upstream
ytm-rs is maintained by grapedjuice and contributors.
